## Summary
Software Advice (and its sibling GetApp) host the same Capterra-pool reviews of Infigo under the "Catfish" product profile. Aggregated themes from the user-written sections are useful for triangulating against your own pain points and for setting expectations with new hires.

## Key takeaways
- Same Capterra reviewer pool, surfaced under the "Catfish" profile name on Software Advice / GetApp / Capterra UK. Useful citation diversity but no new content beyond what's captured in `capterra-infigo-reviews-aggregated.md`.
- Recurring themes across all three sites:
  - Powerful + flexible storefront and template engine.
  - JavaScript required to unlock the dynamic templates story.
  - Documentation gaps on advanced scripting & APIs.
  - Two design systems (Infigo Designer + MegaEdit) = doubled learning curve.
  - Admin UI has too many settings on some screens; features move with updates.
  - Excellent support response (≤12 h typical).
- **Quote ASU Print Lab finding (third-party reported in Infigo-published case study but echoed elsewhere): average order time cut in half after Catfish; 1,200 templates condensed to 200; 120+ business-card templates collapsed to 5** — useful template-rationalization benchmark for any our shop storefront cleanup.
