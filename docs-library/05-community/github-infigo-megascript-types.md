## Summary
Official type declarations for Infigo's MegaScript workflow/automation engine — the server-side scripting layer that automates imposition, file prep, dynamic-product creation, and JDF/finishing connectivity. MIT-licensed npm package `@infigo-official/types-for-megascript`. Auto-generated docs at https://infigo-official.github.io/types-for-megascript/.

## Key takeaways
- MegaScript is the engine behind Infigo's "Smart Imposition" claim of up to 80% reduction in file-prep time.
- Per Infigo's own description of how it's used: "MegaScript checks the folder structure, layout match, and ensures each MegaEdit product has the correct number and type of fields. A temporary dynamic product is created. Each field (e.g. Img1, Barcode) is filled using source PDFs or generated data. The final imposed file is built and saved."
- Distinct from pricing scripts (storefront-side, JS, return a price) and MegaEdit scripts (editor-side, runs in browser). MegaScript is server/workflow-side.
- Browsable type definitions are the only public surface — Infigo Academy course is gated.
