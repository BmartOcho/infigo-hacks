## Summary
Foundational article: Product Attributes are options/add-ons/features (size, lamination, color, stock). Two-step model: create the attribute "group" (at Catalogue > Attributes > Product Attributes), then attach it to a product variant with a prompt + control type + values. Each value can adjust weight, dimensions, and price.

## Key takeaways
- Step 1 — Create the attribute (the "group"): **Catalogue > Attributes > Product Attributes > Add New**. Fill in name, friendly name, description.
- Step 2 — Attach to product: **Catalogue > Products > Product Management > Edit > Product Variant > Edit > Attributes tab > Add new record**.
- Per-attribute setup on the product: label/prompt (what customer sees), Required flag, **Control Type**.
- **Control Type options:** dropdown list, radio button, checkbox, textbox, multiline textbox, date picker, **file upload** (customer artwork), info, html schema, hidden.
- After Insert + Save and Continue Edit, use **View/Edit Attribute Values** to add the dropdown options / values.
- Per-value, you can adjust weight, dimensions, and **price** (delta from base cost).
- **File upload supported extensions:** jpg, jpeg, png, gif, bmp, pdf, csv, txt, tiff, tif, xls, xlsx, ai.
