## Summary
Official developer reference for Infigo's Pricing Script engine. Documents the Item.*, attribute, tier, file, configuration, helper, and output objects/APIs available to custom pricing scripts. Companion NPM type declarations package: `@infigo-official/types-for-pricing-script` for TypeScript/JavaScript IntelliSense.

## Key takeaways
- Full interface doc lives at: **https://infigo-official.github.io/types-for-pricing-scripts/**
- NPM package for type defs: `@infigo-official/types-for-pricing-script` — install in any TS/JS project to get full IntelliSense when authoring custom pricing scripts.
- Covers: items, attributes, tiers, files, configuration, helpers, outputs.
- This is the canonical reference for writing CUSTOM pricing scripts (not the Generic Pricing Script).
