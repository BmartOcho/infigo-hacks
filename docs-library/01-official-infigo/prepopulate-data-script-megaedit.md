## Summary
MegaEdit script that auto-fills specific text fields in a MegaEdit product using data already in the customer's account (name, email, address, custom profile fields). Useful for business cards, address labels, and any personalized product where the buyer is the recipient.

## Key takeaways
- Enable per-product, not globally.
- Path: **Admin > Catalog > Product Types > MegaEdit > MegaEdit Products > Edit the product > Scripts tab > Enable "Prepopulate Data Script" > Save**.
- Fills text fields automatically when the editor loads — no customer input needed.
- Sources: standard customer profile fields PLUS any custom profile fields you've defined.
- Fields are still editable in the editor — prepopulation is just a default.
