## Summary
High-level pitch for the Generic Pricing Script as a time-saver — one CSV in Global Additional Data can drive pricing across many products. Update the CSV once and re-upload to push price changes everywhere instantly. Covers basic + tier + custom pricing options and where the generic script fits.

## Key takeaways
- Infigo supports four pricing approaches: basic static, tier pricing in the UI, custom pricing scripts (full code), and the Infigo-provided Generic Pricing Script (CSV-driven, no code).
- Generic Pricing Script lets ONE CSV drive MANY products — assign the same script to multiple products with the same pricing structure.
- Bulk price updates = swap the CSV in Global Additional Data; new prices propagate immediately without touching products.
- CSVs can have any number of attribute columns, plus quantity column, plus price column. Splitting across multiple CSVs is supported.
- Tier pricing works inside the generic script — different rows for different quantity breaks of the same attribute combo.
- Access to Global Additional Data may need to be requested from the support team if not already available on your account.
