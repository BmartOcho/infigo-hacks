## Summary
Walks through the MegaEdit editor UI from a customer/admin perspective. Covers Back/Menu, canvas size switcher, editor settings (snap-to-grid/objects/free, ruler), zoom controls, the page bleed visual indicators (black + red boxes), and the left-hand tabs: Fields, Images (galleries), Pages, Tools.

## Key takeaways
- Top-left: Back (returns to product landing page) + Menu (general editor settings — admin-only items appear under "Admin Product Options" heading).
- Canvas size: shown in menu; click to switch to alternate canvas if product is configured to allow it. Switching triggers an aspect-ratio warning when applicable.
- Common functions in menu: Clear Page (reset all elements on current page), Reset (revert all changes), Editor Settings (snap-to-grid, snap-to-objects, free mode, ruler toggle), Canvas Settings.
- Top-center zoom controls: `+`, `-`, Reset Zoom, Enable Fullscreen.
- **Page bleed visualization:** the editor shows a BLACK and a RED box around the canvas. Area between black and red = bleed (will be CUT OFF in output). Critical for prepress sanity-check.
- Left-side tabs (default state):
  - **Fields** — add Image fields and Text fields (admin-only or customer-facing, configurable)
  - **Images** — upload + manage image GALLERIES (drag & drop from gallery to canvas; can replace into existing image placeholder frames)
  - **Pages** — add new pages (limited by product config), switch between pages
  - **Tools** — empty by default, populated via configuration
- Bottom-left: Collapse menu button (gives more canvas room) + Preview button (if enabled) + Add to Basket.
- Admin Product Options section in Menu = admin-only configuration controls.
- Default colors come from the storefront's Appearance Settings (admin area) — brand-customizable.
