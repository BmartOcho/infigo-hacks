## Summary
Master integrations directory on the PrintIQ site. Lists every officially-supported partner with a one-paragraph description and outbound link. Important for understanding PrintIQ's wider ecosystem and where Infigo sits in the W2P partner tier.

## Key takeaways
- **W2P storefront partners:** Infigo, Vpress, PageDNA, XMPie (via VDP), plus OnPrintShop.
- **Prepress/RIP partners:** Enfocus (Switch + PitStop bundle), HYBRID Software (CLOUDFLOW + PACKZ), Ultimate Tech (Impostrip Automation), HP (PrintOS/Box).
- **Accounting partners:** QuickBooks, Xero — both pass contact/order/accounting data bidirectionally.
- **Tax partners:** Avalara (US-focused tax compliance), TaxJar (US sales tax — known from Infigo plugin side).
- **Payment partner:** Windcave (PCI-compliant gateway, 20+ payment methods, big in ANZ).
- **CRM partners (via IQconnect-API/Integrate):** HubSpot, Zoho, Salesforce.
- **Freight partner:** New Forest Digital — custom-built freight integrations between PrintIQ and courier platforms.
- **PageDNA has public docs (a rare PrintIQ partner that does):** https://pagedna.my.site.com/docs/s/article/integration-pagedna-printiq-bridge — worth a look as a comparable integration model.
- The Enfocus bundle requires specific modules: PitStop Pro & Server, Switch Core Engine, Configurator Module, Metadata Module, Scripting Module, Switch Client Module, Database Module.
