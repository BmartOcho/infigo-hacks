## Summary
Invent is Infigo's Adobe InDesign plugin. It turns a static InDesign artwork file into a dynamic, customer-personalisable MegaEdit product by defining resources, variables, forms, and conditional logic inside InDesign, then exporting a `.MEX` package that is imported into MegaEdit on the Infigo storefront. The handoff model is: **Invent → export MEX → import into Infigo → customer personalises in MegaEdit**. Customers never see InDesign — they only see the MegaEdit editor.

## Key takeaways
- Invent runs inside Adobe InDesign as an extension panel; the MEX package is the artifact that crosses the boundary into MegaEdit.
- Invent surfaces in Academy span 6 sections: Getting Started, MegaEdit and Invent, Resources, Variables, Forms, Exporting, FAQ.
- Related sub-areas: **Invent Logic** (`c/250`) for conditional rules, **Advanced Grouping** (`c/405`) for grouped variable interactions.
- Updating a MEX file in MegaEdit **overwrites** any direct MegaEdit edits made since the last import — Invent is the source of truth for everything it owns.
- Some MegaEdit features Invent doesn't yet support (e.g., Batch) can still be configured directly in MegaEdit after import, but the disconnect is real (see [[invent-variable-logic]] caveat on CSV batch).
- Pathway is rated Intermediate, ~3 hours, last updated 31 Mar 2026.
