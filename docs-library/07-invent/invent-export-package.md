## Summary
How to export a MEX package from Invent. Save the InDesign file first, navigate to the Export tab, set an export file path and name, click Export. Pre-export summary shows field count, variable count, resource sets, page count, package size. Validation failures (and unsaved changes) block export.

## Key takeaways
- **Save before every export** — required, not optional.
- Export tab shows summary: fields, variables, resource sets, pages, total size.
- `Set Export File` defines the output path + filename.
- `Export` button triggers the package build.
- Validation errors are displayed pre-export and must be resolved first.
- Common validation pain (per comments): "AUTO height" on a frame triggers a validation error with no direct fix path. Workaround = manually key in the auto-set height value InDesign shows in brackets.
