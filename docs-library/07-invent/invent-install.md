## Summary
How to install the Invent plugin into Adobe InDesign. Requires two downloads: the Invent plugin file itself (form-gated download from Infigo) and an Adobe Creative Cloud Extension Manager (Anastasiy or AEScripts). Then enable inside InDesign via Window → Extensions → Infigo Invent. A manual install fallback exists for stubborn machines.

## Key takeaways
- Download Invent plugin from the form on the article page (gated — sign-in required).
- Extension Manager options:
  - **Anastasiy** — https://install.anastasiy.com/ (preferred per docs)
  - **AEScripts** — https://aescripts.com/learn/zxp-installer/ (fallback if Anastasiy fails)
- Install flow: open Extension Manager → select InDesign in left pane → Install → pick the downloaded plugin file → confirm.
- Must close and reopen InDesign after install — plugin won't appear in Extensions menu until restart.
- Enable: InDesign → Window → Extensions → Infigo Invent. Can be docked alongside native InDesign panels.
- Supported InDesign versions: latest only (16+ as of doc date).
- If both Extension Managers fail, see the [Manual Installation Guide](https://academy.infigo.net/academy/p/1586).
